SECTION 01

Expedition 884-B // Mission Briefing

CLASSIFIED FILE 1938-B

In late autumn of 1938, an archaeological team dispatched by the Oxford Antiquities Board un-earthed a reinforced field bunker in Syrian Sector IV. Inside, preserved within an airtight lead-lined container, researchers recovered a rare mechanical cryptographic rotor device cataloged as Artifact OX-1938-C4.

Due to extensive thermal damage to the machine's primary gear assembly, the rotor mechanism remains seized in its original displacement orientation. Only a single encrypted paper tape transmission survived intact inside the internal mechanical drum reader.

Analyst Task Objective

Your task is to analyze the recovered transmission stream, determine the structural shift pattern of the seized rotor wheel, and recover the confidential plaintext message—including the primary expedition recovery flag identifier.

              NOVEMBER 4, 1938
              Dr. Aris Thorne, Lead Epigraphist
              Oxford Conservation Lab 3
            

            
Entry I: Initial Physical Assessment of Seized Mechanism

            

              The device was delivered to the department this morning wrapped in waxed linen. Upon opening the outer steel casing, we observed heavy scoring on the primary bronze driving gear.
            

            

              Unlike complex polyalphabetic machines utilizing stepped rotor stepping levers (such as the Commercial Enigma or Hebern devices), this earlier design utilizes a single static rotary wheel disc with 26 fixed contact pins. The rotor disc is seized firmly against its indexing detent. Consequently, every character typed on the transmitter was shifted by a constant integer offset \(k\) along the standard alphabet sequence \(\text{A-Z}\).
            

          


          

            

              NOVEMBER 12, 1938
              E. Vance, Conservation Technician
              Metallurgy & Cryptanalysis Vault
            

            
Entry II: Frequency & Structural Observations

            

              We executed a complete character count of the tape paper reel. The letter 'S' appears with disproportionate frequency (38 occurrences), followed closely by 'C' and 'O'. In typical military dispatches written in English, the letter 'E' is statistically the most frequent letter.
            

            

              Furthermore, examining line 8 of the dispatch reveals a structured string formatted as wbfccaqht{...}. Historical protocol dictates that expedition flag identifiers were prefixed with the standard token inroomctf{...}. Comparing the positions of 'w', 'b', 'f', 'c', 'c', 'a', 'q', 'h', 't' against 'i', 'n', 'r', 'o', 'o', 'm', 'c', 't', 'f' should immediately reveal the exact mechanical displacement step of the seized wheel.

        REFERENCE ACCORDION
      

      

        

          The following reference notes provide theoretical cryptanalysis methodologies for junior researchers analyzing static rotary substitution ciphers.
        


        


          

            
              NOTE A.1
              Frequency Analysis on Monoalphabetic Substitution Ciphers
              
            
            

              

                In a standard Caesar shift cipher, every letter in the alphabet is shifted by a constant distance \(k\). Because the relative ordering of letter frequencies is preserved under a uniform shift, the frequency distribution histogram retains its characteristic shape but is translated horizontally by \(k\) positions.
              

              

                By identifying the most frequent ciphertext letter (e.g. S) and mapping it to the expected English high-frequency letter E, one can calculate candidate shift values:
              

              

                \(\text{Shift } k = (\text{ord}(\text{Ciphertext}) - \text{ord}(\text{Plaintext})) \pmod{26}\)
              

            

          


          

            
              NOTE A.2
              Known-Plaintext Attack using Known Format Headers
              
            
            

              

                When a transmission contains standardized header keywords or flag formats (e.g. inroomctf{...} or SECRET), a known-plaintext attack provides an instant solution:
              

              
    
                
  • Compare wbfccaqht (Ciphertext) to inroomctf (Target Plaintext).
    • 
                
  • Calculate distance: w \(\rightarrow\) i (Shifted by 14 positions forward in alphabet cycle).
    • 
                
  • Verify across remaining letters: b \(\rightarrow\) n (+14), f \(\rightarrow\) r (+14), c \(\rightarrow\) o (+14), a \(\rightarrow\) m (+14), q \(\rightarrow\) c (+14), h \(\rightarrow\) t (+14), t \(\rightarrow\) f (+14).

              NOTE A.3
              Python Offline Decryption Template
              
            
            

              
Researchers wishing to solve the transmission using Python or bash may download the raw text file and run the following script:

              
def decrypt_caesar(ciphertext, shift):
    plaintext = []
    for char in ciphertext:
        if 'A' <= char <= 'Z':
            plaintext.append(chr((ord(char) - ord('A') - shift) % 26 + ord('A')))
        elif 'a' <= char <= 'z':
            plaintext.append(chr((ord(char) - ord('a') - shift) % 26 + ord('a')))
        else:
            plaintext.append(char)
    return ''.join(plaintext)

# Try shifts 0 through 25 to recover the dispatch
with open('encrypted_transmission_OX1938C4.txt') as f:
    ct = f.read()
    for s in range(26):
        print(f"=== SHIFT {s} ===")
        print(decrypt_caesar(ct[:120], s))
